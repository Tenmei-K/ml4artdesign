# Cars Driving — p5.js sketch

A little street scene drawn with [p5.js](https://p5js.org): cars and trucks
cruise along a four-lane road in both directions, keep distance from the car
ahead, and wrap around at the edges of the screen.

**Click anywhere** to add a car.

## Run it

Just open `index.html` in a browser (double-click it, or `open index.html`).

No build step or install needed — p5.js is loaded from a CDN.
